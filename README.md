# From Stable Placement to Grasp-Aware Placement:
## A Robot-Independent Geometric Manipulation Proxy for Quality-Diversity Robotic Placement

PlaceIt is a Quality-Diversity (QD) framework for generating stable object placements.

This repository extends the original **PlaceIt** framework proposed by Ferrad *et al.* by introducing the **Robot-independent Geometric Manipulation Proxy (RGMP)**, which evaluates and ranks mechanically stable placements using the proposed **Grasp Friendliness Index (GFI)** for downstream robotic manipulation.

Unlike conventional placement evaluation based solely on stability, RGMP provides a robot-independent geometric assessment of placement suitability for robotic grasping while preserving the Quality-Diversity philosophy of PlaceIt.

# RGMP Contributions

Compared with the original PlaceIt framework, RGMP introduces:

- Height evaluation
- Workspace-centrality evaluation
- Uprightness evaluation
- Grasp Friendliness Index (GFI)
- Placement ranking
- Experimental export pipeline for robotic manipulation

These additions transform stable placement generation into grasp-aware placement evaluation while remaining independent of any specific robotic platform.

- NumPy
- OpenCV

---

# Installation

Create a virtual environment and activate it:

```bash
python3.10 -m venv qdp
source qdp/bin/activate
```

Launch the installer:

```bash
./launchers/installer.sh
```

---

# Launch

Always activate the virtual environment before running the framework:

```bash
source qdp/bin/activate
```

## Placement Generation

### Display mode (sequential visualization)

```bash
python3 run_qd_place.py -a cma_mae -nbr 2000 -p 20 -o ycb_mug -t table -ii -d
```

### Parallel execution

```bash
python3 run_qd_place.py -a cma_mae -nbr 2000 -p 20 -o ycb_mug -t table -ii -ll
```

### Parallel execution with different initial z positions

```bash
python3 run_qd_place.py -a cma_mae -nbr 2000 -p 20 -o ycb_mug -t table -ii -ll -n 3
```

# Visualizing Output

Replay placements from a completed run:

```bash
python3 visualization/replay_poses.py -r path_to_run_folder/
```

Shuffle placements before replay:

```bash
python3 visualization/replay_poses.py -r path_to_run_folder/ -si
```
