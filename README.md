# From Stable Placement to Grasp-Aware Placement:
## A Robot-Independent Geometric Manipulation Proxy for Quality-Diversity Robotic Placement

PlaceIt is a Quality-Diversity (QD) framework for generating stable object placements.

This repository extends the original **PlaceIt** framework proposed by Ferrad *et al.* by introducing the **Robot-independent Geometric Manipulation Proxy (RGMP)**, which evaluates and ranks mechanically stable placements using the proposed **Grasp Friendliness Index (GFI)** for downstream robotic manipulation.

Unlike conventional placement evaluation based solely on stability, RGMP provides a robot-independent geometric assessment of placement suitability for robotic grasping while preserving the Quality-Diversity philosophy of PlaceIt.

---

## ICARA 2027 — Updated Reproducibility Package (V3)

The latest ICARA 2027 evaluation investigates when
geometric placement descriptors help, when they fail,
and how robot-specific feasibility can refine
placement selection.

The updated experiments include:

- Seven-method retrospective Franka Panda evaluation.
- Four-object comparison of geometric ranking policies.
- Retrospective robot-specific static admissibility.
- Physical TIAGo GFI versus random-placement validation.
- Additional physical Mug tilted/upright experiments.
- Experimental CSVs, final figures, plotting scripts,
  and frozen Panda configurations.

**Main findings:**

- Panda centrality-only: 35/40 successful selections (87.5%).
- Panda original GFI: 30/40 (75%).
- Panda GFI with retrospective admissibility: 37/40 (92.5%).
- Equally screened centrality-only: 38/40 (95%).
- Physical TIAGo GFI: 279/300 successful grasps (93%).
- Physical TIAGo random baseline: 126/300 (42%).
- Additional Mug trials: tilted 8/10; upright 7/10.

The Panda admissibility analysis is retrospective,
not a prospectively validated feasibility predictor.
Physical Mug orientation results are based on individual
placements and should not be interpreted as complete
ranking-policy comparisons.

# RGMP Contributions

Compared with the original PlaceIt framework, RGMP introduces:

- Height evaluation
- Workspace-centrality evaluation
- Uprightness evaluation
- Grasp Friendliness Index (GFI)
- Placement ranking
- Experimental export pipeline for robotic manipulation

These additions transform stable placement generation into grasp-aware placement evaluation while remaining independent of any specific robotic platform.

## ICARA 2027 — Extended Experimental Evaluation

This repository contains the extended experimental evaluation of the
Robot-independent Geometric Manipulation Proxy (RGMP), developed as
a geometric prioritization layer for Quality-Diversity robotic
placement archives.

The original PlaceIt CMA-MAE placement optimization is unchanged.
RGMP ranks stable archived placements before downstream
robot-specific grasp planning and execution.

### Grasp Friendliness Index

The fixed geometric ranking uses three dimensionless descriptors:

- Height: H = z / L_H
- Centrality: D = exp(-sqrt(x² + y²) / L_D)
- Uprightness: U = exp(-sqrt(phi² + theta²) / theta_0)

The ranking score is:

GFI = 0.5 H + 0.3 D + 0.2 U

Reference scales are L_H = 1 m, L_D = 0.1 m, and theta_0 = 1 rad.

These coefficients are fixed engineering preferences rather than
parameters learned from grasp outcomes.

### Evaluation Summary

**Placement archives:** 2,091 stable placements across six
YCB objects: Mug, Bowl, Spoon, Banana, Plate, and Power Drill.

**Franka Panda simulation:** 154 ranking-selected, deduplicated
placements across five objects were independently evaluated.
Of these, 101 completed dynamic grasping successfully.
The evaluated population is not a random or independent
held-out sample of the complete placement archives.

**Matched-budget ranking evaluation:** At K = 10 evaluated
placements per object (50 selections total):

| Ranking | Successful selections |
|---|---:|
| Full GFI | 30/50 |
| Centrality only | 35/50 |
| Height only | 29/50 |
| Uprightness only | 37/50 |
| Height + Centrality | 35/50 |

**Height-removal ablation:** Removing H from GFI preserves the
same top-ten ordering in the five evaluated Panda object sets.
The resulting centrality + uprightness ranking produces the
same matched-budget selection outcomes as full GFI.

**TIAGo physical experiments:** Across Mug, Bowl, and Spoon,
60 placements and 600 grasp attempts were evaluated.
GFI-ranked placement selection achieved 93% mean grasp
success versus 42% for the tested distance-stratified random
baseline, with a placement-level bootstrap difference interval
of 35.0 to 66.7 percentage points.

The TIAGo comparison does not demonstrate superiority over
centrality-only or centrality + uprightness placement selection.

### Scope and Limitations

RGMP is a geometric placement-prioritization heuristic, not a
robot-independent grasp-success predictor. Its predictive
discrimination is object-dependent, and competing geometric
rankings sometimes achieve better selection performance.

Downstream robot-specific feasibility, grasp planning,
contact evaluation, and execution remain necessary.
